# Умная косметичка Moonlight Princess

Косметичка хранит до пяти снимков каждого средства в существующей базе `asya-photos` (IndexedDB). База обновляется с версии 1 до версии 2 без удаления старого хранилища `photos`: прежний снимок по ключу средства становится обложкой. Порядок хранится в `galleries`, локальные снимки перед восстановлением копии — в `backups`. Пользовательские `ananas:` записи, схема ухода и рекомендации не меняются. Снимки и порядок входят в экспорт, импорт и копию Яндекс Диска. При превышении 24 МБ экспорт предлагает уменьшить фото.

Распознавание выполняет встроенный Tesseract.js с локальными русской и английской моделями. Фотографии не отправляются на сервер распознавания. Даты изготовления не предлагаются как срок годности; неоднозначные даты и значения вроде `12M` помечаются как требующие проверки. Значения переходят в форму только после ручного подтверждения и сохраняются после нажатия «Сохранить». Значок баночки определяется лишь эвристически и может распознаваться неточно. HEIC/HEIF доступны, только если браузер умеет декодировать их; при ошибке можно сохранить снимок как JPEG.

Service Worker обновляет только кеш `asya-`, не затрагивая localStorage и IndexedDB. Статические OCR файлы кешируются после первого применения; без ранее загруженных файлов первое распознавание офлайн недоступно. Safari и приложение с экрана Домой могут хранить данные отдельно. Для первого перехода сначала экспортируйте копию в прежней версии, затем установите обновление и проверьте наличие данных; если хранилище оказалось отдельным, импортируйте копию через «Ещё» с просмотром конфликтов. Не выполняйте полную замену без скачанной копии.
