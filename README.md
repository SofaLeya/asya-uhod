# Асина Умывалочка · Moonlight Princess

Самостоятельное приложение для Асиной схемы ухода. Исходные процедуры, средства и рекомендации сохранены в этом репозитории. Код не загружает файлы из другого приложения.

## Соответствие возможностей

| Возможность | Асина версия до обновления | Moonlight Princess |
| --- | --- | --- |
| Утро и вечер | Отметки `ananas:YYYY-MM-DD`, выбор средств `ananas:prod` | Те же ключи и шаги, компактные вкладки, прогресс и редактор |
| Курс | `ananas:start`, календарь азелаиновой кислоты | Та же первая неделя и последующий график; дневник и история календаря |
| Средства | Три исходных ARAVIA и пользовательские названия | Косметичка с фото, сроками, остатками и поиском; рекомендации о покупке не становятся приобретёнными средствами |
| Резервные копии | Файлы `asya-uhod` v1, Яндекс Диск, Telegram | Версионированный v2 с фото; старые файлы принимаются; слияние показывает конфликты |
| Яндекс Диск | `app:/data.json` | Новые записи `app:/asya-uhod-data.json`; старый файл доступен только для чтения при восстановлении |

Данные Софьиного приложения имеют другой префикс (`skin:`), другую базу фотографий, отдельный облачный файл и другой идентификатор копии. Асина версия их не читает и не экспортирует. Service Worker удаляет при обновлении только старые кэши `asya-*`.

## Безопасное восстановление

1. Открой «Ещё» → «Резервная копия» и скачай текущую копию.
2. Выбери «Восстановить из файла» или в панели Яндекс Диска нажми «Восстановить с Диска».
3. Просмотри количество конфликтов. Для сохранения текущих записей выбери «Слить данные».
4. «Полностью заменить» используй только если нужно заменить данные на устройстве: появится отдельное подтверждение, а приложение сохранит локальную копию состояния до замены.

Новый файл на Яндекс Диске имеет отдельное имя. Старая копия `data.json` не перезаписывается. Системные уведомления при полностью закрытом браузере не поддерживаются: напоминания показываются внутри приложения.

## Проверки

`npm ci`, `npm run lint`, `npm run test:unit`, `npm run build`, `npm run test:e2e`. Браузерные тесты используют Playwright и локальные заглушки Яндекс Диска и Telegram. Реальные аккаунты в тестах не используются.
